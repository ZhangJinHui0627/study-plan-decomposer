## 一、 数据库结构表设计 (`tasks` 表)

采用 SQLite 数据库存储本地学习任务，数据库文件为 `studyplan.db`。

```sql
CREATE TABLE tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,                  -- 任务标题/学科
    content TEXT,                         -- 任务详细描述/页码
    target_duration INTEGER DEFAULT 0,    -- 目标专注时长 (分钟)
    completed_duration INTEGER DEFAULT 0, -- 已专注时长 (分钟)
    overflow_duration INTEGER DEFAULT 0,  -- 溢出计时时长 (分钟)
    is_completed INTEGER DEFAULT 0,       -- 完成标记 (0:未完成, 1:已完成)
    created_time LONG NOT NULL,           -- 创建毫秒时间戳
    reminder_time LONG DEFAULT 0,         -- 提醒毫秒时间戳
    category TEXT DEFAULT '通用'           -- 学科分类
);
```

## 二、 核心 CRUD 接口方法

在 `TaskDatabaseHelper.java` 与 iOS `StudyPlanStore.swift` 中定义统一的数据访问接口：

1. **`long insertTask(Task task)`**：插入新解析生成的任务，返回自增 ID。
2. **`List<Task> getAllTasks()`**：按创建时间倒序查询所有任务列表。
3. **`boolean updateTaskStatus(long id, boolean isCompleted)`**：更新任务完成状态。
4. **`boolean updateFocusTime(long id, int addedMinutes, int overflowMinutes)`**：累加任务专注时长与溢出时长。
5. **`boolean deleteTask(long id)`**：删除指定任务。
