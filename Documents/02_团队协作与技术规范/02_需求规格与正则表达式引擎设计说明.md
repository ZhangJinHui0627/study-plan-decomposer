# 需求规格与正则表达式引擎设计说明

- **文档版本**：V1.0
- **撰写人**：张锦慧
- **面向模块**：`TaskParser` 正则提取引擎及文本预处理层

---

## 一、 需求概述

针对生成式 AI 或学生口述产生的非结构化学习计划文本，系统需在移动端本地秒级完成提取，并结构化转换为 `Task` 模型。

待提取字段包括：
1. **时间/日期信息**（如：“明天”、“下周一”、“19:00”）
2. **专注时长**（如：“30分钟”、“1.5小时”）
3. **任务数量/页码**（如：“第3章”、“P12-P45”）
4. **学科/主题关键词**（如：“英语”、“高数”、“Java开发”）

---

## 二、 预处理与正则表达式匹配规则设计

### 1. 文本预处理 (`TextPreprocessor`)
在进行正则匹配前，执行如下清洗步骤：
- 全角字符转半角；
- 过滤无效修饰词（如“请帮我”、“打算”、“可能”）；
- 统一时间单位（将“一小时”标准化为“60分钟”）。

### 2. 正则表达式规则配置库

```java
// 时间与时长提取正则示例
public static final Pattern DURATION_PATTERN = 
    Pattern.compile("(\\d+(\\.\\d+)?)\\s*(分钟|小时|min|h)", Pattern.CASE_INSENSITIVE);

// 章节与页码提取正则示例
public static final Pattern PAGE_PATTERN = 
    Pattern.compile("(第[0-9一二三四五六七八九十]+章|P?\\d+\\s*[-~至]\\s*P?\\d+页?)", Pattern.CASE_INSENSITIVE);

// 日期解析正则示例
public static final Pattern DATE_PATTERN = 
    Pattern.compile("(今天|明天|后天|下周[一二三四五六日]|\\d{1,2}月\\d{1,2}日)");
```

---

## 三、 规则库扩展机制

为适配不同专业（如计算机、医学、法学）的特殊术语，引擎内置本地学科字典扩展机制（`SubjectRulesView`）。用户或系统可动态追加学科正则表达式列表，提升匹配覆盖度。
