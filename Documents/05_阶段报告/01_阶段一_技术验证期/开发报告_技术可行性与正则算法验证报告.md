# 阶段一开发报告：技术可行性与正则算法验证报告

- **所属阶段**：阶段一（市场调研与技术验证期）
- **日期区间**：2026.05.07 — 2026.06.30
- **主要责任人**：张锦慧、郭泽坤

---

## 1. 本阶段研发目标
验证使用 Java 原生正则表达式在 Android 移动端提取非结构化学习计划文本的可行性，评估 CPU/内存开销，确定轻量化路线。

## 2. 研发工作内容
1. 收集市场上主流 AI 产生的学习计划格式特征（按天/按周/按章节）；
2. 搭建正则表达式原型引擎 Demo，测试 `Pattern` 与 `Matcher` 在 Android 平台上的编译执行效率；
3. 确定“预处理清洗 + 分层正则表达式匹配 + 学科词库补充”的三层提取架构。

## 3. 技术验证结论
原生正则表达式在移动端执行速度极快（平均 $< 30\text{ ms}$），完全不需要依赖云端 API 或本地轻量大模型，技术可行性 100%。
